# MLNC Sports Arena

A responsive college sports portal for:

MOTILAL NEHRU COLLEGE (UNIVERSITY OF DELHI)

## Files
- index.html — complete website structure
- style.css — responsive modern design
- script.js — schedule filtering, registration interaction and mobile menu

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For VS Code, install/use Live Server and open `index.html` with Live Server.

## Included features
- Responsive homepage
- Sports cards
- Tournament section
- Match schedule with sport filter
- Team leaderboard
- Sports gallery
- Player registration form
- Mobile navigation
- Form success message

Note: This version is a frontend academic project. The registration form is interactive in the browser but does not save data to a server/database. A FastAPI + MySQL backend can be connected later.
